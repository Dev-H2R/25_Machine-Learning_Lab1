# 25_Machine_Learning_Lab

This repository contains the practical assignments and experiments conducted for the Machine Learning Lab course.

## Repository Structure

The repository is organized into three folders, with each folder containing the practical notebook and the required dataset.

### ML_LAB1 - Exploratory Data Analysis

This practical focuses on Exploratory Data Analysis (EDA) and data preprocessing using the Titanic dataset.

**Files:**
- `ML_Lab1_25.ipynb` - Jupyter Notebook containing the implementation.
- `Titanic-Dataset.csv` - Dataset used for analysis.

**Topics Covered:**
- Data loading and inspection
- Data cleaning
- Missing value handling
- Duplicate detection
- Outlier detection and handling
- Exploratory Data Analysis

### ML_LAB2 - Machine Learning Practical 2

This practical focuses on the implementation and analysis of machine learning concepts using the given dataset.

**Files:**
- `ML_Practical_2.ipynb` - Jupyter Notebook containing the implementation.
- `processes2.csv` - Dataset used for the practical.

### ML_LAB3 - Concept Learning Algorithms

This practical focuses on fundamental concept learning algorithms.

**Files:**
- `ML_Lab3.ipynb` - Jupyter Notebook containing the implementation.
- `enjoy.csv` - Dataset used for training the algorithms.

**Algorithms Covered:**
- Find-S Algorithm
- Candidate Elimination Algorithm
- Version Space
- Specific and General Boundaries

## Common Prerequisites

To run these practicals, ensure the following are installed:

- Python 3.x
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn
- Jupyter Notebook

## How to Run

1. Open the required lab folder.
2. Open the `.ipynb` file using Jupyter Notebook or Google Colab.
3. Make sure the required dataset is available in the same folder.
4. Run the notebook cells in order.

## Conclusion

This repository provides hands-on experience with various Machine Learning concepts, including data preprocessing, exploratory data analysis, and concept learning algorithms.
